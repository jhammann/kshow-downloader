# Agent instructions

## Committing and pushing

- You may commit to `master` and push it to `origin` whenever a piece of work is done; no need
  to ask first.
- Use conventional commit messages (`feat:`, `fix:`, `docs:`, `ci:`, ...). A pushed `feat:` or
  `fix:` commit produces a new release (semantic-release tags it, Woodpecker builds the image).
  That is expected and fine; don't avoid those prefixes or ask for confirmation because of it.
