# Agent instructions

## Committing

- You may commit to `master` whenever a piece of work is done; no need to ask first.
- Use conventional commit messages (`feat:`, `fix:`, `docs:`, `ci:`, ...). A `feat:` or `fix:`
  commit produces a new release once it reaches `master` on GitHub (semantic-release tags it,
  Woodpecker builds the image). That is expected and fine; don't avoid those prefixes or ask
  for confirmation because of it.
